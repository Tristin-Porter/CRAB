================================================================================
ARCHITECTURE EVOLUTION
================================================================================

OLD ARCHITECTURE:
  AST Node → String Template → String Output
  - Simple placeholder substitution
  - No type safety
  - Limited to strings

NEW ARCHITECTURE:
  AST Node → Semantic Model → Typed Emitter → WASM IR
    ↓           ↓                ↓               ↓
  Fields    .Using()         .Emit()        Objects
                                               ↓
                                          .ToWat() → WAT
                                          .Encode() → .wasm

BENEFITS:
  - Type-safe code generation
  - Semantic transformations
  - Multiple output formats
  - Composable emitters
  - Full backward compatibility
