TASK COMPLETION: Fix WASM Generation for Multiple Class Members
================================================================================

PROBLEM
-------
WASM generation only output the first method in a class, ignoring all others.

Example Input:
    class Calculator {
        int Add(int a, int b) { return a + b; }
        int Subtract(int a, int b) { return a - b; }
    }

Previous Output:
    (func $Add ...)  ← Only first method
    
Expected Output:
    (func $Add ...)
    (func $Subtract ...)  ← Both methods


ROOT CAUSE
----------
CDTk library bug in ExtractFields method (Dependencies/CDTk/Boilerplate/CDTk.cs)
- When parsing repetitions like "members:ClassMemberDeclaration+"
- Code would exit loop after first item: if (fieldIndex >= fieldNames.Count) break;
- Discarded all remaining items (methods, classes, statements, etc.)


FIX APPLIED
-----------
File: Dependencies/CDTk/Boilerplate/CDTk.cs
Lines: 13427-13468 (35 lines modified)

Strategy:
1. Collect ALL non-literal items (removed early exit)
2. Detect repetition patterns (1 field name = likely repetition)
3. Create list for multiple items (enables CDTk template joining)
4. Assign single items directly (avoid type inconsistency)
5. Maintain backward compatibility (non-repetitions unchanged)
